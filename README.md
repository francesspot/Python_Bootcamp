# 🐢 Python Bootcamp — OOP i gry (dzień 16+)

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

> 🎓 Kurs **100 Days of Code: The Complete Python Pro Bootcamp** (Angela Yu, Udemy)

Ciąg dalszy kursu (pierwsze 15 dni jest w [Python_Basics](https://github.com/francesspot/Python_Basics)). Ta część skupia się na **programowaniu obiektowym** i grach z grafiką w module `turtle`.

## 🕹️ Projekty

| Projekt | Co przećwiczyłem |
|---|---|
| **Snake** — z rekordem zapisywanym do pliku | klasy, kolizje, zapis/odczyt pliku |
| **Pong** dla dwóch graczy | obsługa klawiatury, fizyka piłki |
| **Turtle Crossing** — coraz szybsze poziomy | zarządzanie wieloma obiektami |
| **Wyścig żółwi** z obstawianiem zwycięzcy | zdarzenia, losowość |
| **Hirst Painting** — obraz z kropek w kolorach wyciągniętych ze zdjęcia | biblioteka `colorgram` |
| **Quiz** | własne klasy (`Question`, `QuizBrain`) |
| **Ekspres do kawy** w wersji obiektowej | podział na klasy |
| **Mail Merge** — personalizowane zaproszenia dla listy gości | operacje na plikach |

## 🚀 Uruchomienie

```bash
pip install prettytable colorgram.py   # potrzebne tylko w dwóch projektach
cd snake_game
python main.py
```
